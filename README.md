# 🚀 Space Kids — Explore the Solar System

A fun, interactive website that helps kids explore our Solar System. Watch the planets orbit the sun, click through to learn fun facts about each one, and dive into kid-friendly videos and articles.

🔗 **Live site:** https://space-kids-app.netlify.app

## ✨ Features

- **Animated home page** — the sun glows at the center while all 8 planets orbit around it at different speeds
- **Planet explorer** — scroll through every planet, planet by planet
- **Planet detail pages** — facts about size, distance from the sun, moons, temperature, and fun facts, with a smooth entrance animation
- **Resources page** — a kid-friendly YouTube video and a short summary/Wikipedia link for each planet
- **Glassmorphism design** — a frosted-glass navbar and footer that respond as you scroll
- **Built for kids** — bright colors, playful fonts, and simple navigation

## 🛠️ Built with

- [React](https://react.dev/)
- [TanStack Router](https://tanstack.com/router)
- [GSAP](https://gsap.com/) for animations
- [Tailwind CSS](https://tailwindcss.com/)
- [Vite](https://vitejs.dev/)

## 🧑‍💻 Running locally

```bash
npm install
npm run dev
```

Then open the local URL printed in your terminal (usually `http://localhost:8080`).

## 📁 Project structure

- `src/routes/` — pages (home, planet list, planet detail, resources)
- `src/components/` — Navbar, Footer, Starfield, Planet rendering
- `src/lib/planets.ts` — all planet data (facts, images, video IDs, links)
